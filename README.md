## 🟣 Featured Projects

<details open>
<summary><b>🎓 Lumina Tutor — Adaptive Instructional Design · Gagné × Merrill · LangGraph</b></summary>

<br/>

An AI-powered instructional design and tutoring system that creates structured learning experiences and adapts its teaching approach when learners struggle.

The project combines **Gagné's Nine Events of Instruction** and **Merrill's First Principles of Instruction** to guide lesson design and practice.

<div align="center">

| Aspect | Details |
|---|---|
| **Stack** | Python, Streamlit, LangGraph, Groq, Pydantic, HTML/CSS/JavaScript |
| **Instructional Design** | Gagné × Merrill |
| **AI Workflows** | Lesson generation, simulated student evaluation, iterative content improvement |
| **Adaptive Learning** | Error tracking, alternative teaching strategies, learner signals |
| **Quality Checks** | Pacing validation, assessment checks, content repair loop |
| **Human-in-the-Loop** | Structured teacher handoff when learners repeatedly struggle |
| **Repository** | [View on GitHub](https://github.com/AfzalManihar/lumina-tutor-Agent) |
| **Live Demo** | [Try Lumina Tutor](https://lumina-tutor-agent.streamlit.app/) |

</div>

**How it works:** The lesson-building workflow creates and checks learning content, while the tutoring workflow tracks exercise attempts and learner difficulties. When repeated attempts fail, the system can generate a structured handoff packet with error patterns and suggested next steps.

**Key features:**

- Structured lesson and exercise design
- Simulated student testing
- Adaptive teaching strategies
- Attempt and error tracking
- Teacher handoff and revisit scheduling
- Metrics and engine trace views

**What I learned:** Designing AI workflows that combine generation, evaluation, iterative improvement, adaptive teaching, and human oversight.

</details>
